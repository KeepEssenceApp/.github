# .github

KeepEssenceApp 组织的公共文件。

| 路径 | 作用 |
|---|---|
| `profile/README.md` | 组织主页上显示的介绍 |
| `CONTRIBUTING.md` | 贡献指南，对组织下没有自带该文件的仓库生效 |
| `CODE_OF_CONDUCT.md` | 行为准则 |
| `SECURITY.md` | 安全问题怎么报 |
| `.github/ISSUE_TEMPLATE/` | 缺省的 issue 模板 |
| `.github/PULL_REQUEST_TEMPLATE.md` | 缺省的 PR 模板 |

某个仓库需要不同的模板时，在那个仓库里放同名文件即可覆盖。
